Parte 1

Propriedades do Flex Container

Estas propriedades são aplicadas ao elemento que contém os itens.

Flex Container

flex-direction

Define a direção do eixo principal e a ordem em que os itens são apresentados.

Organiza os itens horizontalmente, da esquerda para a direita.

flex container Eixo principal → Eixo secundário ↓
1
2
3
4
.container {
    display: flex;
    flex-direction: row;
}
Flex Container

justify-content

Distribui e posiciona os itens ao longo do eixo principal.

Posiciona todos os itens no início do eixo principal.

flex container Eixo principal →
1
2
3
4
.container {
    display: flex;
    justify-content: flex-start;
}
Flex Container

align-items

Alinha todos os itens ao longo do eixo secundário.

Estica os itens no eixo secundário quando eles não possuem tamanho fixo nesse eixo.

flex container Eixo secundário ↓
1
2
3
4
.container {
    display: flex;
    align-items: stretch;
}
Flex Container

gap

Define o espaçamento entre os itens, sem criar margens nas extremidades do container.

Cria 10 pixels de espaço entre linhas e colunas.

flex container
1
2
3
4
5
6
.container {
    display: flex;
    flex-wrap: wrap;
    gap: 10px;
}
Flex Container

flex-wrap

Controla se os itens permanecem em uma única linha ou quebram para novas linhas.

Mantém todos os itens na mesma linha, mesmo quando falta espaço.

flex container
1

    display: flex;
    flex-wrap: nowrap;
}
Flex Container

flex-flow

É a forma resumida de definir flex-direction e flex-wrap.

Organiza os itens em linha e impede a quebra para novas linhas.

flex container

    display: flex;
    flex-flow: row nowrap;
}
Flex Container

align-content

Distribui as linhas de itens no eixo secundário. Só produz efeito quando há quebra de linha e espaço livre.

Estica as linhas para preencher o espaço disponível no eixo secundário.

flex container com múltiplas linhas

Parte 2

Propriedades dos Flex Items

Estas propriedades são aplicadas individualmente aos elementos internos.

Flex Item

order

Altera a ordem visual do Item 3 sem modificar a ordem dos elementos no HTML.

Mantém o Item 3 na posição definida pelo HTML.

Item 3 selecionado
1
2
3selecionado
4
5
.item-3 {
    order: 0;
}
Flex Item

flex-grow

Distribui proporcionalmente o espaço livre. Os itens comuns possuem valor 1; apenas o Item 3 será alterado.

O Item 3 participa do crescimento na mesma proporção que os demais.

Demais itens: flex-grow: 1
1
2
3selecionado
4
5
.item-3 {
    flex-grow: 1;
}
Flex Item

flex-shrink

Define quanto o Item 3 pode encolher quando o espaço do container é insuficiente.

Largura do container:

O Item 3 encolhe na mesma proporção que os demais.

Reduza a largura para aumentar o efeito
1
2
3selecionado
4
5
.item-3 {
    flex-shrink: 1;
}
Flex Item

flex-basis

Define o tamanho inicial do Item 3 antes do navegador distribuir ou retirar espaço.

Usa o tamanho definido pela largura ou pelo conteúdo do item.

Item 3 selecionado
1
2
3selecionado
4
5
.item-3 {
    flex-basis: auto;
}
Flex Item

flex

Forma resumida de definir flex-grow, flex-shrink e flex-basis.

Não cresce, pode encolher e usa o tamanho automático como base.

Item 3 selecionado

Flex Item

align-self

Substitui o alinhamento definido pelo container apenas para o Item 3.

Herda o align-items: center definido no container.
